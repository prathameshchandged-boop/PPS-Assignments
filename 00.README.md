# PPS Assignments

This repository contains C programming assignments and lab exercises for the Programming for Problem Solving (PPS) course.

---

## Index of Programs

1. **Hello World**
   * **File:** `01_HelloWorld/hello_world.c` (or `01_Hello_World.c`)
   * **Description:** A simple introductory program that prints "Hello World" to the standard output.

2. **Sum of Two Numbers**
   * **File:** `02_SumOf2Numbers/sum_2_numbers.c` (or `02_Sum_of_2_Numbers.c`)
   * **Description:** Takes two integers as input from the user and outputs their sum.

3. **Compare Two Numbers**
   * **File:** `03_CompareTwoNumbers/compare_two_numbers.c` (or `03_Compare_Two_Numbers.c`)
   * **Description:** Compares two user-inputted integers to determine which one is larger or if they are equal using conditional (`if-else`) statements.

4. **Sum of 10 Numbers**
   * **File:** `04_SumOf10Numbers/sum_10_numbers.c` (or `04_Sum_Of_10_Numbers.c`)
   * **Description:** Reads 10 integers from the user and calculates their total sum.

5. **Simple Calculator**
   * **File:** `05_SimpleCalculator/simple_calculator.c` (or `05_Simple_Calculator.c`)
   * **Description:** Menu-driven calculator performing Addition, Subtraction, Multiplication, and Division operations using a `do-while` loop and `switch` case.

6. **Matrix Addition**
   * **File:** `06_MatrixAddition/matrix_addition.c` (or `06_Matrix_Addition.c`)
   * **Description:** Performs element-wise addition on two 2D matrices of user-defined row and column dimensions.

---

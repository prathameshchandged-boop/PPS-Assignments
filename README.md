# PPS Assignments

This repository contains C programming assignments and lab exercises for the Programming for Problem Solving (PPS) course.

---

## Index of Programs

1. **Hello World**
   - **File:** `01.Hello World.c`
   - **Description:** A simple introductory program that prints "Hello World" to the standard output.

2. **Sum of Two Numbers**
   - **File:** `02.Sum of 2 Numbers.c`
   - **Description:** Takes two integers as input from the user and outputs their sum.

3. **Sum of 10 Numbers**
   - **File:** `03.Sum Of 10 Numbers.c`
   - **Description:** Reads 10 integers from the user and calculates their total sum.

4. **Compare Two Numbers**
   - **File:** `04.Compare Two Numbers.c`
   - **Description:** Compares two user-inputted integers to determine which one is larger or if they are equal using conditional (`if-else`) statements.

5. **Simple Calculator**
   - **File:** `05.Simple Calculator.c`
   - **Description:** Menu-driven calculator performing Addition, Subtraction, Multiplication, and Division operations using a `do-while` loop and `switch` case.

6. **Matrix Addition**
   - **File:** `06.Matrix Addition.c`
   - **Description:** Performs element-wise addition on two 2D matrices of user-defined row and column dimensions.

7. **String Operations**
   - **File:** `07.String Operations.c`
   - **Description:** Menu-driven program performing string length (`strlen`), concatenation (`strcat`), copy (`strcpy`), and comparison (`strcmp`) operations using `<string.h>`.

8. **Factorial (With & Without Recursion)**
   - **File:** `08.Factorial Using Recursion.c` / `08.Factorial Without Recursion.c`
   - **Description:** Calculates the factorial of a user-inputted number using both recursive function calls and an iterative `for` loop.

9. **Student Result Using Structure**
   - **File:** `09.Student Result Using Structure.c`
   - **Description:** Accepts student details (roll number, name, branch, and 5 subject marks) using an array of `struct` variables and computes total marks, percentage, and class/grade.

10. **Swap Two Numbers (Call by Reference)**
    - **File:** `10.Swap Two Numbers.c`
    - **Description:** Swaps the values of two integers by passing their memory addresses via pointers (`call by reference`).

11. **Copy File Contents**
    - **File:** `11.Copy File Contents.c`
    - **Description:** Uses file handling (`fopen`, `fgetc`, `fputc`, `fclose`) to read characters from a source file and copy them into a destination file.

12. **Calendar Preparation**
    - **File:** `12.Calendar Preparation.c`
    - **Description:** Generates and displays a formatted monthly calendar for any given year and month, accounting for leap years and starting day of the week.
